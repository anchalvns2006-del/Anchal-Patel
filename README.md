</p>🚆 RailNova AI — Railway Intelligence Dashboard
A data analytics and machine learning project that studies railway routes and predicts timetable-derived journey duration using route-level features.
- Dataset scale: 186,074 station records and 11,113 train-route combinations.
- Build: Python, Pandas, NumPy, scikit-learn, Plotly and Streamlit.
- Highlights: Route analytics, feature engineering, grouped model evaluation and an interactive dashboard.
- Live dashboard: Open RailNova AI
- Repository: RailNova-AI
<sub>Model scope: timetable-based journey-duration estimation, not live delay prediction.</sub>
⛏️ OreSight AI — Mining Prospectivity Intelligence
A Smart India Hackathon concept for using AI/ML and space technology to support manganese reserve prospectivity and mining intelligence (PS26009).
- Build: React, FastAPI, SQLAlchemy, SQLite, Pandas and scikit-learn.
- Focus: Prospectivity mapping, production insights, equipment intelligence and satellite-informed workflows.
- Repository: OreSight-AI
🎟️ EventSphere — Event Registration Platform
A full-stack event registration platform with authentication and event workflows.
- Build: Node.js, Express, MongoDB, JWT and bcrypt.
- Repository: CodeAlpha-Event-Registration
🍽️ DineFlow — Restaurant Management
A restaurant operations application covering menus, orders, reservations, inventory and reports.
- Build: Node.js, Express, MongoDB and JavaScript.
- Repository: DineFlow-Restaurant-Management
📊 Netflix Data Analysis
An exploratory data analysis project focused on content patterns and interactive storytelling.
- Analysis: 8,790 records and 35 interactive Plotly visualizations.
- Build: Python, Pandas, NumPy, Matplotlib and Plotly.
- Repository: Auspify-Netflix-Data-Analysis
